# 液态玻璃测试页面

从底部导航第四项“测试”进入。页面使用主导航本身，沿用当前通透度、运动方式和固定/自动隐藏偏好。

浅色、深色、左右明暗交界、照片、文字五个快捷按钮用于定位背景；每块背景有足够高度覆盖实际导航栏。上下滚动让文字、图片、细线和颜色边界经过玻璃，观察颜色自适应、倒像、边缘压缩和折射。返回其它栏目时测试页释放，再次进入从浅色背景开始。

两张 NASA 摄影打包在 `src/static/glass-lab/`，无需联网，来源说明见该目录的 README。页面不保存、修改用户课表。

主导航与设置预览共享 `navigation-items.ts`，滑块按实际栏目数计算宽度；设置中的往返演示会到达最右栏目。

备份与恢复：`.backup/glass-test-page-before-20260928-122519/RESTORE.md`。

已验证：类型检查、35 项相关单元测试、H5 / App 构建；实际测试页快速定位、图片本地采样、深浅切换、明暗交界，以及 320 / 390 / 768px 下的第四栏目对齐与无横向溢出。通透度设置、预览及四栏目长按/跳跃切换回归通过。导航回归首次遇到浏览器命令超时，单独重跑通过。截图和浏览器报告位于 `.artifacts/glass-adaptive/`、`.artifacts/glass-live-preview/` 和 `.artifacts/nav-hop/`。
