# 湖畔课表实施状态

本次交付已从关键页面视觉验收推进到「Android 本地导入可验证」节点。课程页面结构和 SEP 登录兼容性仍必须在真实 Android 设备上确认。

## 已实现

- 标准 uni-app App-Vue 工程，Vue 3、TypeScript、Pinia、SCSS。
- Android 桌面小组件源码：详细今日课表与简洁当前/下一节课程、整学期离线快照、保存同步、独立实例设置、跳转与省电定期刷新。前端构建、UTS 生成、Kotlin 编译和原生资源链接已验证；最终 APK 与真机桌面尚待验证，见 [小组件说明](android-widgets.md)。
- 七列周课表、教学周选择、手势切周、真实日期计算、下一节课提示。
- 多组上课安排、间断节次拆分、重叠课程分组与逐项查看；同名课程族不会被误标成课程冲突。
- 课程详情；导入后的课程名称、教师、地点、颜色编辑会持久保存到本机。
- 日常、密集、冲突、空课表四种视觉验收场景。
- 今日课程、学期信息、减少动画的预览入口。
- Android 导入由 UcasImportSession 协调 xkgo 选修课程元数据、个人课表和课程详情。课程代码、主讲教师、学位课和考试方式直接从当前 xkgo 选修课程表读取；星期、周次、节次和地点来自个人课表及课程详情，缺失项目在预览页列出。手机模式先展开导航栏。自动化测试通过不等于学校真机登录通过。
- Android 导入页默认以手机模式直接打开 SEP，不再先加载空白 WebView；个人课表入口不便操作时可切换到电脑模式。电脑模式会在同一个 WebView 中应用桌面 User-Agent、`setUseWideViewPort(true)`、`setLoadWithOverviewMode(true)`、初始缩放和可缩放状态；支持时通过页面开始加载事件注入桌面 viewport。切换不会显示过渡页。
- 导入时保持当前 WebView，读取结束后释放页面以恢复预览滚动。预加载文件放在 src/static/ 并核验打包产物。AndroidX DOCUMENT_START_SCRIPT 支持时注册 SEP 源限定脚本，不支持时使用 setJsFile（不可用才 appendJsFile）和当前页面注入。跨文档重新初始化防护，重开不重复绑定原生事件。日志使用 [UCAS import v2] 前缀且不包含登录凭证。
- 登录入口为 `https://sep.ucas.ac.cn/`，当前选课系统主页为 `https://xkgo.ucas.ac.cn:3000/courseManage/main`，选修课程页通常是带学期标识的 `https://xkgo.ucas.ac.cn:3000/courseManage/main-<学期标识>`（也兼容 `/courseManage/selectedCourse`），个人课表为 `https://xkgo.ucas.ac.cn:3000/course/personSchedule`。课程详情会跳到 `https://xkcts.ucas.ac.cn:8443/course/coursetime/<id>`；读取流程在当前 xkgo 会话中提取所有选修课程元数据，然后发现严格校验过的详情链接，在同一登录 WebView 中逐个打开课程详情读取上课安排。课程详情按时间、地点、周次字段的顺序配对，并以“星期/节次/周次”作为唯一安排键，重复行只升级待确认地点，不再串用相邻地点；元数据优先按课程编码匹配，只有课程编码缺失且名称唯一时才按名称匹配，同名不同编码不会误填教师或考试方式。脚本仅在这些精确来源执行，并保留端口与详情路径校验；它只通过临时原生存储回传课程名称、课程编码、教师、是否学位课、考试方式、地点、星期、节次和周次。密码输入框、Cookie、完整页面 HTML 和登录会话不读取、不保存、不上传；预览完成、取消或失败后临时结果会删除。
- 导入结果经过数据范围、来源和字段校验，部分课程失败时保留失败清单；确认保存前不会覆盖现有本地课表。
- 首页和导入页均不再启用页面级 `disableScroll`；首页由独立的课表 `scroll-view` 负责纵向滚动，导入预览和表单使用独立的 flex 滚动区域，避免 Android 基座的页面级触摸阻止监听触发 passive `preventDefault` 警告或拦截下拉。

## 尚未完成／不得宣称通过

- 含小组件的 Android APK：需要兼容的 HBuilderX/UTS 原生环境和现有包名、签名配置；当前已有 DCloud AppID，仍需完成云打包与真机桌面验收。
- SEP 登录跳转、当前页面选择器和 `plus.storage` 临时回传：需要安卓真机验证，目前未实际登录。解析器覆盖公开旧实现中的课程详情表格结构，但学校页面变化时需要适配。
- 同学期重新导入的差异比对与逐项冲突确认、学期作息编辑、备份恢复、课前通知和云同步尚未实现。
