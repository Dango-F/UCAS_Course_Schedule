# 导航液态玻璃：随背景明暗切换

## 参考与范围

参考视频：`E:/xwechat_files/wxid_p17ge98c7zjn22_257d/msg/video/2026-09/faa6d069d92a1efa677a81b4f09f4f73.mp4`。

视频中背景照片滚过底部导航时，浅背景使用深色图标/文字，深背景使用浅色前景，玻璃表面也随之改变深浅。这不是仅跟随系统深色模式。关键帧概览保存在 `.artifacts/glass-adaptive-study/overview.png`。

本轮使用 frontend-design 的既有设计延续原则：保留胶囊轮廓、图标体系、运动和通透度，只增加与背景相关的对比度响应。不重新设计导航栏。

## 实现

- 独立 `glass-adaptive.js` 模块，由外层 `installGlassLens` 安装一次，销毁时清理；主导航和设置预览共用。
- 每栏目三个内侧采样点，各栏目独立决定文字/图标明暗；整体有效采样决定表面和选中胶囊的深浅。不是把整张图片平均成一种颜色。
- 深背景进入阈值为线性亮度 0.17，退出阈值为 0.24，减少中灰附近反复切换。图标、文字、表面底色与阴影的过渡统一为 200ms；判断阈值和 160ms 采样间隔保持不变。
- 通过命中栈估算背景色并合成透明层；可读取图片按展示裁剪位置取样。图片首次读取缩为 64×64 并缓存，至多 64 张；不逐帧截图、不发送像素到外部服务。
- 由滚动、内容变更、图片加载、尺寸和可见性变化触发，采样间隔至少 160ms。静止后无轮询；导航隐藏时不读取背景。不经过 Vue 每帧响应式链路。
- 不改折射图生成、色散滤镜、7px 倒像、压缩/交界弯折参数和滑块运动。深浅变化只影响表面底色、阴影、选中项底色/亮度，以及图标文字对比度。
- 系统要求减少透明度/增强对比度时退出自适应，沿用原来的不透明无障碍样式；减少动态效果时关闭新增颜色过渡。

## 准确性边界

这是受控的 DOM/图片背景估算，不是浏览器合成结果的逐像素读取。支持普通背景颜色、可安全读取的图片以及部分同源单图背景（cover / contain / 100% 100%）。

跨域且未授权的图片、视频、Canvas、内联 SVG、复杂渐变等不会强行读像素；无法得到可靠采样时保留最后一次有效状态，首次默认原来的浅色材质。任意滤镜、伪元素、组透明度、旋转和 `pointer-events:none` 绘制层也可能与命中栈估算不完全一致。因此并不承诺任意网页内容均能像系统合成器一样判断。

依据：浏览器 [CORS 图片与画布限制](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image)、[命中检测语义](https://developer.mozilla.org/en-US/docs/Web/API/Document/elementFromPoint)、[getImageData](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/getImageData)。不更改用户图片的跨域配置，也不使用代理绕过安全限制。

## 验证

- 深浅背景往返与逐栏目混合明暗；
- 实际 PNG 的局部像素采样与缓存；
- 实际滚动切换、静止不轮询；
- 不支持的 Canvas 保留上次状态；
- 关闭效果恢复原来的材质，系统无障碍优先；
- 销毁后停止工作。
