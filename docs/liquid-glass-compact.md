本页记录本日早期的常驻版本。后续已修正折射纹理坐标、改善松手连续性，并按用户重新确认的要求恢复滚动显隐，见 [最新记录](liquid-glass-continuity.md)。

## 范围与视觉

沿用当前三项「课表 / 今日 / 设置」、56px 高、4px 内边距、48px 按钮、底部 20px 加安全区。
常驻底栏，不恢复旧自动隐藏。只优化底栏，不修改课表 V2 翻页、课程布局、今日/设置页或加载呼吸圆点。

依据 frontend-design 的克制原则：沿用纸白、石墨、雾灰及系统字体，把变化集中在玻璃厚度和触摸反馈，不增加新的颜色、装饰或整页动效。

- 折射边缘随高度缩放：56px 时 rim≈12.44px、最大采样位移≈7.78px、blur≈1.94px；不再沿用 72px 底栏的完整强度。中心保持中性。
- 稍减外阴影，径向触点光的尺寸随底栏高度变化。
- 一个按压进度同时控制亮面、内外接触阴影、横向拉伸和纵向压缩。阴影本身固定，靠伪元素透明度改变，不逐帧重写阴影参数。
- 两端按实际余量限制选中块拉伸，避免三等分的大胶囊越过外壳。
- SVG ID 按安装实例生成，避免重复实例引用同一个滤镜。

## 运动与连续操作

`glass-navigation.js` 只在视图层处理运动，不把逐帧位置写入 Vue。

- 拖动：位移直接跟手，保留非中心抓取点；接管尚未完成的运动时从当前可见位置继续。
- 切换/松手：解析临界阻尼弹簧，位置频率 `.03/ms`、按压频率 `.038/ms`，使用实际时间步长；下一次目标改变保留当前位置和速度。移除选择器上的 CSS 位移补间，避免两套动画追赶。
- 精确收敛后停止 rAF；静止按住在速度/按压进度稳定后也停止。失焦、尺寸变化、隐藏或禁用会复位；卸载清理监听与观察器。
- 真实触摸验证发现某些 uni-app H5 输入序列没有后续原生 click，因此有效 pointerup 同时提交点击和拖动；抑制重复物理 click，新按下清除旧守卫，键盘/程序点击仍可用。
- 指针移出底栏范围或取消触摸不提交切页。弹层期间底栏 inert，关闭后恢复常驻。
- 减少动态使用即时位置；减少透明度或增强对比度使用实色并停用折射。

## 性能与功能边界

仍只有外壳一层真实 backdrop 折射。选中块的按压覆盖层不是第二个透镜。
位移纹理只在挂载或尺寸改变时生成，不逐帧抓取课表、不重建课程 DOM、不在课表滚动时计算光学参数。
但实时背景滤镜仍有 GPU 成本；无闲置 JS 写入不等于没有合成成本或真机不掉帧。

未新增：选中项独立背景/图标折射、色散、像素级背景亮暗自适应、融合形变、原生 Compose 插件。
仍是对 Kyant Shader 胶囊折射思路的 WebView 移植，不宣称完整等价原生库。
来源与许可沿用 [前轮资料复核](liquid-glass-refinement-review.md) 和源码 Apache-2.0 声明。
