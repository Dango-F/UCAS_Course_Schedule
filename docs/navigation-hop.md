# 导航跃动模式（2026-09-21）

入口：设置 → 外观与交互 → 导航切换。

- 流动：保留原来的速度相关拉伸与弹簧动画。
- 跃动：长按选中胶囊鼓起，点击切换时放大、移动、缩小，到达目标时恢复尺寸。
- 选择独立保存于 `lakeside:nav-motion:v1`；没有历史选择时默认跃动，读取到明确的流动值仍保留流动，异常或未知值回退为跃动。写入失败会提示，当前选择仍可体验。

## 视觉与时序

遵循 frontend-design 技能，在现有玻璃胶囊上增加纵向厚度和有限的横向扩张，不重画导航或修改课表。
最大横向缩放 1.12、纵向 1.38，向上抬起 2px，附近图标/文字最多放大 1.07。
首尾栏目以内侧为扩张方向，防止超出屏幕。原胶囊高 48px，按住后约 66px。

按压表面改为低不透明度渐变（约14% → 0.8% → 4.7%），取代原先约90% → 61% → 68%的白色覆层；保留细边高光并减弱底边反光和外阴影。长按和移动共用此材质，不改变动画尺寸、时长或原流动模式。

移动默认 320ms，原地按压/恢复 160ms。移动与尺寸共用一个基于 elapsed time 的进度：
位置用 smoothstep，普通切换的放大量用 sin²(π × 移动进度)。不是匀速平移，而是均衡的起落；尺寸与位移同帧完成，没有到站后的独立弹簧尾巴。
长按移动至被按栏目后保持鼓起，松手再完成导航与恢复。快速点击则在移动过程中完成完整起落。
页面/选中图标在松手确认时更新；不额外延迟页面跳转到动画结束。

快速反向从上次实际画面的位置/尺寸重新出发，保持数值连续，不保证速度一阶连续。
拖动期间位置直接跟手；取消或越界松手返回当前栏目。按住不动和动画结束后不保留 RAF 循环。
系统或应用减少动画优先，直接定位而不放大。窗口失焦、页面隐藏、尺寸变化清理按压状态。

## 结构

`glass-hop.js` 独立实现新模式。`glass-navigation.js` 的入口按配置选择控制器，原流动控制器逻辑保留；模式变化先销毁旧监听、动画与滤镜再创建新控制器。
`NavigationMotionSetting.vue` 只管理选择 UI，`appearance` store 持久化。
CSS 新规则仅由 `.is-hop` 启用，不改变玻璃通透度预览或旧流动模式外观。
