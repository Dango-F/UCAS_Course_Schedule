# 选中滑块整面泛白修复（2026-09-29）

用户澄清：闪烁是整个滑块泛白，不是宽飘带断续。本轮保留 wide-ribbon-v12 的场算法、形状、颜色、方向、包络与速度。

## 复现与修改

- 旧材质把整个滑块的 brightness 从 .94 推到 1，同时撤掉底色、加入按压白色渐变。灰色固定背景实际截图的中心亮度从 180.60 升到 193.85（0–255）。新材质固定 .94 和用户设定的底色透明度，按压只改变形状、边缘阴影、折射强度与局部飘带，取消按压整面白色渐变。
- 旧 resize 无论导航实际尺寸是否改变都会 halt：一次未改变尺寸的事件便把按压值 1 置为 0、滑块缩回、亮度重置为 180.60。流动/跳跃控制器现在只在实际尺寸改变时重置。
- 旧选择器在按压开始/结束时添加/删除 SVG url()。现在缓存滤镜在可用时持续挂载，零压力时位移 scale 为零；压感折射、色散和 depthEffect 仍沿原时钟变化。不新增位移图、不在运动时重新编码图像。该处属于合成管线跳变风险修复，没有单独证明它是某款 WebView 泛白的原因。
- 背景明暗自适应保留；选择器底色也使用现有 200ms 过渡，不再瞬间切换整面滤镜亮度。正式导航与设置预览共享修复后的 CSS。

## 验证

97 项相关测试、类型检查、H5/App 构建通过。App 产物包含修复后的 CSS 与 renderjs。

浏览器真实截图把流动飘带临时隐藏以隔离材质，保持同一灰色背景，测试真实按住、同尺寸 resize、取消：跳跃模式中心亮度约 181.31 → 182.63；流动模式约 181.32 → 182.91，resize 后保持原亮度与按压状态。余下微小亮度差来自局部边缘反光/形变的合成，不存在旧约 13/255 的整面增亮。该隔离仅发生在测试浏览器，产品飘带未关闭。

完整宽飘带浏览器回归通过：持续原生滑动时整面滤镜字符串与底色 opacity 稳定；120 连续帧、快速再次触摸、深浅背景切换、900ms 阻塞恢复、松手停止、透明度预览、无障碍与空闲无写入检查通过，异常为空。与另一个浏览器检查并行时出现一次原有快速接续断言失败；保留原阈值独立复测通过，不能仅凭复测确定该失败原因。
