# 历史：触摸黑白流光

## 参考与范围

参考用户视频 `945e5ec9fc05c84018d18655201dba6b.mp4` 的底部导航，结合后续要求：整个滑块内呈现缓慢流动的河水状曲线光影，不局限于边缘，不忽明忽暗。参考帧保存在 `.artifacts/glass-flow-light-study/`。

本轮新增独立的 CSS 明暗反光层，不修改现有折射、色散、depthEffect、7px 倒像、200ms 背景明暗过渡以及 flow/hop 的位移和碰撞算法。它是触摸驱动的高光近似，不是从视频或实时环境重建的物理光照。

## 行为

- 页面触摸移动超过 6px 后，整个选中滑块出现连续的弯曲明暗光带；累计移动距离驱动相位，反向滑动使相位反向。
- 直接长按导航也显示同一光带；页面滚动不会因此切换栏目。
- 持续接触期间亮度固定为 0.52，不随 touchmove 的频率和速度衰减/重启。手指停住后位置逐渐收敛，停止逐帧更新，但不突然熄灭。松手后才淡出，不随惯性滚动自动循环。
- 中央不镂空，三条有明暗侧边的曲线覆盖整个滑块内部，仍在图标下面。没有整片均匀白色蒙层。
- 不再旋转光斑。纹理位移为横向手指距离的 0.06 倍、纵向的 0.045 倍，平滑时间常数 120ms，并限制流速不超过 16 纹理像素/秒。松手冻结在当前相位再淡出，不倒放复位。
- 页面隐藏、导航隐藏、配置切换、窗口失焦和减少动态效果偏好均会停止本层。
- 设置预览使用同一模块，独立于主导航实例。

## 实现

`src/components/glass-touch-light.js` 在视图层监听 passive capture 触摸事件。capture 是必要的：uni-app 的 scroll-view 会停止事件冒泡；touch 路径则在原生滚动接管并取消 pointer 事件后仍能工作。模块不调用 preventDefault、不截断原有手势。

`src/static/glass-river-light.svg` 是宽 200px 的静态矢量曲线纹理，左右边界位置和切线相接。`glass-touch-light.css` 以 repeat-x 平铺，仅由 transform 移动；每 200px 归一化位移，接缝不跳变。用多层细描边形成明暗侧边，无实时模糊滤镜。只更新小图层的 transform / opacity；不逐帧读取布局、不触发 Vue 更新、不重建折射位移图、不新增 backdrop-filter。它是曲线反光的视觉模拟，不是流体模拟或背景真实水波折射。
