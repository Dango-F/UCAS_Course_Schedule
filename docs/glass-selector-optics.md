# 选中滑块透镜与材质连续性（2026-09-24）

## 范围与备份

修改前完整备份：`.backup/glass-selector-before-20260924-022650/`，包含 src、scripts、tests、docs。

本轮仅优化已有流动/跃动导航的材质与选中滑块折射。保留当前默认跃动、320ms 移动 / 160ms 原地恢复、放大幅度、通透度默认100、页面跳转和现有显隐规则。没有恢复滚动自动显隐，没有加入色散、背景明暗采样或交互式设置预览。

遵循 frontend-design 的克制材质方向，保留既有图标、字号和配色，厚度靠窄边缘透镜呈现，不增添大面积白色覆层。

## 实现

- 外层继续使用原来的胶囊透镜、模糊和饱和度。
- 选中面使用独立 SVG 位移图：48px 高时边缘宽6px、最大采样位移2.5px；不额外模糊或增强饱和度。图标和文字绘制在透镜之上。
- 位移图仅安装/尺寸改变时生成。按压期间只更新 displacement scale；恢复静止后移除 selector 的 URL 滤镜，仍保留原有亮度处理。没有常驻 RAF 或逐帧截图。
- 两个透镜的变量、SVG ID、生命周期独立，不覆盖外层通透度参数；不支持的引擎保留 CSS 材质，减少透明度/增强对比度时禁用两层折射。
- 材质改为数值 `--glass-material-progress`，统一驱动亮度、底色透明度和表面微光，不再由 `.is-material-clear` 的开关直接切换视觉状态；该类仅作为状态标记保留。
- 跃动材质与既有 lift 同步：中段清透，缩小时渐进恢复，到站同帧结束。
- 流动按当前位置距目标的剩余距离恢复材质，进入0.5px视觉到站范围时完成，不等待较慢的形变/光斑弹簧尾部。同栏目松手用160ms渐退，反向操作从当前材质值接续。

## 验证

- 157 项单元测试、类型检查、H5/App 资源构建通过。
- `verify-nav-hop.cjs`：两种模式真实触摸、长按、反向、取消、同帧收尾、无空闲更新、模式切换清理、尺寸边界通过。
- `verify-selector-optics.cjs`：320/390px 和 DPR 1/2 下，细线背景的边缘像素有明确位移，中央差异接近0；交互不重新编码位移图；静止关闭第二层透镜；减少透明度与强制兼容分支通过。
- `verify-glass-optics.cjs`：外层原有双轴折射、中央中性与零位移对照通过。
- `verify-glass-clarity.cjs`：通透度预览、持久化、对比默认、三份滤镜ID隔离及退出清理通过。
- `verify-glass-nav.cjs`：原流动模式跟手、反向、松手光斑/形变、导航切换、无障碍与320/390/768px布局通过。测试路径补充“退出设置二级页”步骤，避免在已隐藏/inert的导航上测试触摸；未修改正式版页面显隐。
- 光学测试使用细线验证窄边缘的轻微位移；宽纯色色带可能掩盖该变化。效果为局部透镜，不声称物理精确模拟。
- 浏览器验证不等于 Android 真机验收。双透镜仅在交互期间启用，仍需在目标手机对比触摸响应、帧时间与视觉收益；不能据此承诺60/120fps。
