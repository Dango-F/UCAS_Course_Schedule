## 2026-09-25 本轮调整

备份：`.backup/glass-coherence-before-20260925-233536/`，包含修改前的 `src`、`tests`、`scripts`、`docs`。恢复注意事项见该目录的 `RESTORE.md`。

本轮沿用现有布局、配色、通透度参数和两种导航动效，不通过降低折射、色散强度改善观感。

- **轮廓高光**：按胶囊轮廓法线计算边缘受光，中心透明；缓存三个光照方向并随受力方向混合。成功生成后替换重复的固定白色内沿，保留 CSS 兼容回退，不叠加整面白色遮罩。
- **厚度**：选择器预生成四档折射边缘宽度（25%、50%、75%、100%），按按压/跃动进度连续混合相邻位移场；同一进度控制折射幅度、内阴影深度和高光强度。峰值边缘宽度、折射幅度以及七采样色散/depthEffect 均保留。
- **悬浮感**：阴影距离与模糊同时跟随压力和实际腾空高度；用户选择的跃动高度仍然生效。放大时更厚，腾空时投影更远，落地时共同恢复。
- **连续切换**：跃动被再次点击打断时，在导航边界允许的范围内继承水平速度；采用有界曲线抵达目标，落点速度为零，保留原有时长和独立腾空轨迹。
- **贴图精度与生命周期**：位移图和轮廓图最高按 2× 像素密度生成，仅在初始化或尺寸变化时编码；拖动期间只修改已有滤镜参数、贴图引用和样式，不捕获页面、不逐帧编码 PNG，不增加常驻动画循环。

## 实现边界

这是 WebView SVG/CSS 的近似移植，不是直接运行 Compose/AGSL。四档位移场插值不等价于每帧重新执行任意厚度的原始 Shader；三个方向的高光混合也不是实时环境光追踪。完整七采样指本项目已有的光谱采样组合保持完整，并非宣称所有平台与原库逐像素一致。

新增缓存增加初始化工作量；DPR 上限为 2。真实设备仍需要检查初始化耗时、GPU 合成开销及温升，不能从桌面测试推断 Android 120Hz 性能。非兼容浏览器和系统降低透明度/高对比模式仍保留回退。

默认固定导航、可选自动隐藏、通透度设置、实时预览、流动/跃动选择及跃动高度设置均保留。
