# 湖畔课表 1.0.0 · 2026 年 11 月更新

## 新增功能

- **在课表上添加安排。** 长按空白格可添加补课、临时课程、会议或活动，拖动可连选多节。补课会显示在原课程详情里。
- **调课与课程编辑。** 长按课程卡片可移动本次课或拖动边缘调整节次，保存前可对照调整结果。编辑整门课时可增删、复制时段，按单双周排课。课程详情支持复制课名或完整信息，也可只删除某一次、整个时段或整门课。
- **学期设置。** 在「设置 → 学期与导入」可用日历选择第一教学周的周一，修改教学周总数。保存后，课表与桌面小组件同步更新。
- **Android 小组件按课表刷新。** 到上下课时间自动更新状态灯和剩余课程数。设置中可查看下次刷新时间，按需开启「闹钟和提醒」。点按课程可定位到对应教学周和日期。
- **应用内检查更新。** Android 版按手机本地日期，每天第一次联网打开应用或回到前台时自动检查更新。离线打开不计次数，下次联网打开或返回时再查。当天已发出检查请求后，即使请求失败也不会自动重试，仍可在「设置 → 关于湖畔课表」手动检查。更新提示会等课表导入或课程编辑结束后再出现，可选择前往 GitHub 下载、明天提醒或跳过此版本。

## 体验改进与修复

- **课表与弹窗。** 课表、今日页和课程详情的布局更紧凑。滑动换周时，松手后的牵引感从中段逐渐增强，对齐时平稳停住。慢拖和快甩各自保持原有时长，中途反向也能从当前位置接着拖动。改善课表上下滚动，以及课程详情和「添加安排」的弹出与收起。修复排列视图切换中断后只剩星期标题、长按单格无法新增安排和选区提前消失的问题。
- **设置与导航。** 设置统一为简洁分组，子页和首页加号打开的导入页统一从右侧滑入。改善首次切换底栏、进出「外观与交互」时的卡顿。
- **液态玻璃。** 改善底栏图标和玻璃边缘的锯齿，修复长按预览滑块时折射提前减弱的问题。柔雾随通透度变化，100 档为零模糊。默认采用流动效果、75 档通透度，滑块光影与 Q 弹默认关闭。
- **桌面小组件。** 修复紧凑版拉高后显示堂数不变的问题，改善五列桌面和旋转屏幕时的排版。宽松版优先显示未结束的课，两款组件共用背景不透明度，并在课表载入前显示提示。
- **启动与导入。** 修复部分 Android 设备启动后首页空白、底栏重叠的问题，改善启动画面淡出、教务网页操作栏和读取完成时的动画衔接。

## 从旧版升级

使用 0.1.0 的同学可下载本页 APK，直接覆盖安装并保留本地课表。已安装早先 1.0.0 的同学也可手动覆盖安装，体验新版切周动画。本次沿用相同的内部版本码，应用内更新提示会在有更高版本码时出现。
