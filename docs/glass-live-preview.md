# 玻璃材质实时预览（2026-09-21）

入口：设置 → 外观与交互 → 玻璃通透度。

## 使用

- 滑条上方增加 176px 高的静态示例课表：三种颜色的课程卡片、课程文字和网格提供观察参照。
- 预览胶囊与正式导航同为 56px 高，拖动滑条时两者同步使用当前通透度。
- 按住「对比默认」临时显示默认档位 100；松手、取消触摸、离开按钮、失去焦点或页面隐藏时恢复当前档位。
- 对比只作用于示例，不改变正式底栏或保存值。支持按住空格/Enter，Escape 取消。
- 数值表示调节档位而非实际透光率；柔雾/均衡/清透提供方向参照。

## 实现边界

`GlassMaterialPreview.vue` 绘制真实 DOM 示例和玻璃，不使用图片模拟。
正式导航与预览共用 `glass-navigation.css`（从正式导航原样抽取）及 `installGlassLens`，因此模糊、覆盖、高光、折射与无障碍回退来自同一套实现。
由于两者宽度及底图不同，不承诺画面逐像素相同；预览用作稳定的材质参照。

`glass-preview.js` 只处理对比和参数更新，不引入手势弹簧、持续动画、课表截图或存储写入。
位移图仍只在挂载/尺寸改变时生成。离开外观页即卸载，清除监听、尺寸观察器和 SVG。
折射滤镜 ID 增加 DOM 占用检查，避免不同 renderjs 包内独立计数器导致预览与正式底栏使用同一个 ID。
系统减少透明度/高对比度优先生效，并在预览下显示解释文字。

本轮使用 frontend-design 技能保持湖蓝/青绿/淡紫的课程配色，把示例、对比按钮和滑条组合成一个连续操作区域，未新增背景自动滚动或装饰动画。

## 验收

- 104 项单元测试通过，包含对比状态、触摸取消、键盘、失焦、页面隐藏和卸载清理测试。
- 类型检查、H5 和 App 资源构建通过。
- `verify-glass-clarity.cjs` 验证真实拖动、预览与正式材质参数一致、滤镜 ID 唯一、按住对比不保存、不影响正式底栏、取消恢复、键盘、实色回退及重新挂载；异常列表为空。
- 同一静止课表区域截图对比确认玻璃像素发生变化，比较区域不包含数值和按钮文字。
- `verify-glass-nav.cjs` 正式底栏回归通过；`verify-settings-categories.cjs` 设置分类回归通过。
- 已查看 320/390px 页面截图和对比前后示例截图。报告/截图位于 `.artifacts/glass-live-preview/`。
- Android 真机的触感、GPU 帧率和旧版 WebView 兼容性仍需真机确认。
