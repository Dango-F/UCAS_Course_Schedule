# 透明玻璃材质优化（2026-09-21）

本轮只调整导航材质，不改导航常驻/弹层显隐、手势弹簧、课表翻页、课程颜色或加载动画。
修改前快照：`.backup/liquid-nav-clear-before-20260921-172435/`，包含 src、scripts、tests、docs。

## 设计与实现

延续 frontend-design 的克制设计方向：保持现有字体、石墨色图标和胶囊布局，中央清透，玻璃厚度集中在边缘。
保留原先参考 Kyant `Shaders.kt` 移植的胶囊折射曲线及 Apache-2.0 声明；没有引入新 Shader 或截图采样。
此前阅读的 `LiquidButton.kt` 以可选表面色与较轻模糊实现玻璃，适合作为减轻白色覆盖的设计参考；
本轮参数是针对本项目细小课程文字的 WebView 调校，不是把原库 dp 数值直接换成 CSS px。

| 参数 | 修改前 | 修改后 |
| --- | --- | --- |
| 56px 底栏模糊 | 约 1.94px | 0.6px；尺寸变化限制在 0.4–0.8px |
| 外层浅色覆盖 | 19% | 6% |
| 选中胶囊灰底 | 8.5% | 4%；按压时仍按已有进度减弱 |
| 选中上沿渐变 | 白色延伸到 55% | 更弱、收窄到 30% |
| 按压上沿渐变 | 延伸到 62% | 更弱、收窄到 34% |
| 触摸光斑 | 白色 alpha 0x70，扩散到 68% | alpha 0x30，扩散到 60% |
| 饱和度 / 折射边带 / 最大采样偏移 | 1.5 / 约 12.44px / 约 7.78px | 不变 |

`glass-lens.js` 的行内滤镜和 Vue 样式的回退滤镜同步降低模糊，避免仅修改 CSS 却被行内值覆盖。
整体导航透明度不变，文字和图标不参与背景滤镜。保留方向性边缘高光、阴影、键盘焦点和实色无障碍模式。
没有增加动画循环、Vue 更新、滤镜层数或逐帧位移图生成。

## 验收

- 80 项单元测试通过，类型检查通过，H5 和 App 资源构建通过。
- `verify-glass-nav.cjs`：常驻显隐、弹层阻断、手指拖动、快速切换、松手连续性、键盘、320/390/768px 布局通过；错误列表为空。
- 校验浏览器实际使用 0.6px 模糊、6% 外层覆盖和 4% 选中灰底，不只检查源代码参数。
- 减少透明度 / 高对比度仍使用实色；减少动画仍取消形变。
- `verify-glass-optics.cjs`：320px@1x、390px@1x、390px@2x 各测横/纵条纹，六组均通过。中央与相同模糊的无位移对照像素差为 0，最优偏移为 0；边缘存在明确像素变化。
- 已查看实际课表、按压状态和设置页截图。对照截图是在相同页面和滚动位置临时还原旧材质，随后移除测试样式，不改课表数据。

报告和截图：`.artifacts/glass-nav-clear/`、`.artifacts/glass-optics-clear/`。
前后对照：`glass-nav-clear/course-backdrop-before.png` 与 `glass-nav-clear/course-backdrop.png`。

更清透也意味着课程内容更容易透到导航下方；深色、密集背景上的可读性仍需真机观察。
浏览器检查不能证明 Android 真机的 60/120Hz 帧率或各 WebView 版本的滤镜兼容性，App 构建通过也不等于真机验收。
