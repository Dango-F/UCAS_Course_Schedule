# 玻璃通透度设置

设置 → 外观与交互新增滑动条，范围 0–100，步长 1。向左柔雾，向右清透。
默认 100 为最高通透档位；数值表示调节档位，不代表物理透光率，0 也不等于完全不透明。
配色、字号与设置页一致，预览保持为静态参照，不增加额外装饰层。

| 档位 | 56px 底栏模糊 | 外层浅色覆盖 | 选中灰底 |
| --- | --- | --- | --- |
| 0 | 2.4px | 25% | 10% |
| 80（均衡） | 0.6px | 6% | 4% |
| 100（默认/最高） | 0.2px | 2% | 2.5% |

折射几何、导航前景颜色、高光和拖动弹簧保持不变。

## 更新与保存

- `GlassClaritySetting.vue` 使用项目内 uni-app slider 的 `changing` 实时预览、`change` 松手保存；支持方向键、Home/End、PageUp/PageDown 和恢复默认。
- `appearance` 独立 Pinia store，只被设置子组件和导航组件订阅，首页/课表组件不订阅滑条值。
- `lakeside:glass-clarity:v1` 独立保存，不改课程信息及现有显示偏好；支持 0、非法存储值回退、保存失败提示和重试。
- 切换页面中断拖动时，子组件卸载会尝试保存最后预览值。重复保存相同值不会再次写入。
- 通过现有 renderjs 配置把值交给玻璃控制器，更新 CSS 参数和实际行内背景滤镜。不读取布局、不重新编码 PNG、不重建位移图。
- 系统减少透明度/高对比度仍覆盖为实色；退出这些模式后恢复用户选择。没有新增永久动画循环。
