# 滑块光影设置与宽度微调（2026-09-29）

“设置 → 外观与交互”中的玻璃预览下增加“滑块光影”开关，沿用现有开关配色、排版和键盘交互。默认开启，保存到独立键 lakeside:glass-touch-light:v1。只在明确保存 false 时关闭；存储不可用或非法值仍默认开启。

正式导航和设置预览的 renderjs 配置都传递 touchLight。关闭时立即 suspend：取消绘制帧、清空场和像素、光影 opacity 归零；关闭期间的触摸不再启动飘带绘制。重新开启后在下一次滑动或长按时恢复，不在空闲时启动动画。原有独立调试关闭标记与系统减少动态/透明度仍有效。

开关控制触摸飘带，不删除玻璃折射、色散、depthEffect、原有边缘阴影，也不改变 Q弹或流动/跃动切换效果。

宽度系数 1.06 → 1.04，约收窄 1.9%；光量按 1.04/1.06 同比调整，避免窄化后归一化将同样光量集中成更亮的峰。流速仍为 .33，轮廓、数量、方向、入场、松手渐隐和泛白修复保持不变。

验证：87 项相关单测、类型检查、H5/App 构建通过。浏览器通过真实设置按钮验证默认开启、正在按压时立即关闭、关闭后触摸不绘制、形变与玻璃仍正常、刷新后正式导航保持关闭、空格键重新开启，以及预览/正式导航恢复实际像素。浏览器异常为空，已检查设置截图。报告：.artifacts/glass-live-preview/touch-light-setting-report.json。
